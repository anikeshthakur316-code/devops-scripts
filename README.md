# DevOps Scripts Collection

Ye repo mere DevOps learning ke Bash scripts ka collection hai.  
Linux server automation aur monitoring ke liye useful scripts.

## Scripts List

### 1. `backup.sh`
Folder ka automatic backup leke `.tar.gz` file banata hai.
**Use:** `bash backup.sh`

### 2. `phone_health.sh` 
Phone/server ki health check karta hai - Disk, RAM, CPU.
**Use:** `bash phone_health.sh`

## Kaise Use Karein
1.  Script ko download karo
2.  `chmod +x script_name.sh` chalao permission dene ke liye
3.  `bash script_name.sh` se run karo

## Topics
`bash` `devops` `linux` `automation` `shell-script`
